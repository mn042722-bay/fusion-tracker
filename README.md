# Fusion Tracker

## 概要
業務データを一元管理・可視化するためのシステムです。

## 背景
Excelやスプレッドシートで分散管理されていたデータを統合し、
リアルタイムで確認できるようにするため開発しました。

## 技術スタック
- PHP（Laravel）
- MySQL
- React（Vite）

## 主な機能
- 認証機能（ログイン）
- データ管理（CRUD）
- ダッシュボード表示
- API連携（フロントとバックエンド分離）

## 工夫した点
- フロントとバックエンドを分離した構成
- 実務を意識したデータ設計
- Cursor × Claudeを活用した高速開発

## 補足
実務での開発内容に近い構成で再現したプロトタイプです。
